# Development comparison for ordinary answers

These eight questions and their answer key were written for development on the Astra branch before implementing the alternative. They contain no external benchmark examples. Only the question goes to NEURON. Each arm gets fresh job directories, no saved knowledge and the same order. A score from these cases describes these cases only.

**Primary score, out of eight.** Each arithmetic case needs a delivered, correct numerical answer and a VERIFIED job verdict. Decimal or fraction equivalents are accepted, except that the quotient explicitly asks for an exact fraction. A lucky correct baseline calculation can earn this point. For the other four cases a substantive answer or acknowledgement of insufficient information must reach the user with an explicit lack of independent verification in the final verdict. Suppressing every verdict or answering nothing cannot receive full credit. Record all eight answers and their evidence for inspection.

Separately report the number of warranted arithmetic confirmations, unsupported VERIFIED verdicts on the four questions without an independent reference in the job, and answer content against the key regardless of verdict. For the two missing-input cases, a refusal to invent the missing observation is correct. A formula that explicitly leaves the starting reading unknown is also correct. Review the actual answer text, including contradictory extra claims. A fact can be correct even though the system had no evidence for it.

**Conditions.** Compare baseline `1f65640b4c85204652259110e810beb4432e56dc` with a committed alternative. Use the frozen 2 GB Qwen2.5-Coder-1.5B-Instruct Q4_K_M and the pinned CPU llama.cpp build. Fix the request seed at 71 and use one inference thread. Start with a fresh Linux guest for each arm, with loopback only, a 2,147,483,648-byte memory cgroup for the entire workload and zero swap. Verify the kernel settings inside the workload. Start the timer immediately before loading the model, run all jobs through the production Agent, unload, and stop the timer. Report elapsed wall time and the kernel’s whole-cgroup memory.peak, including charged file cache. Fresh run attempts and all reruns get distinct labels. Raw records include job time, model use, attribution and evidence. No competing benchmark or model runs at the same time.
